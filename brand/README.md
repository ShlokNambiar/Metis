# Metis — Brand Assets

## Logo
- `metis-logo-light.svg` — primary horizontal lockup (blue mark + ink wordmark) for light backgrounds
- `metis-logo-dark.svg`  — for dark backgrounds (blue mark + white wordmark)
- `metis-logo-blue.svg`  — reversed, on Metis Blue
- `metis-mark-blue|white|ink.svg` — the network mark alone (app icon, favicon)
- Clear space = one node diameter on all sides. Don't recolor, stretch, or rotate the mark.

## Wordmark
Hanken Grotesk, Bold (700), uppercase, ~+0.12em tracking.

## Color
- Metis Blue  #1C46FF  (primary accent)
- Ink         #0E0E0F  (text, dark surfaces)
- Cream       #F3EFE4  (warm surface)
- Rust, Green, Orange — secondary card tones (see tokens/colors.css)

## Type
- Display / UI: Hanken Grotesk (grotesque)
- Editorial: Newsreader (serif) — titles, pull quotes, big numerals
Full tokens in ../tokens/.

Note: logos are SVG (crisp at any size). For PNG/ICO exports, open an SVG in any editor and export at the size you need.
